Language Guide

Learn about each language archetype.

Elvish

Flowing, melodic language with soft consonants and elegant vowel combinations. Features sounds like 'th', 'ph', 'ae', and 'iel'.

Example: "Aelara thiel"

Dwarven

Harsh, guttural language with hard consonants and short vowels. Features clusters like 'gr', 'dr', 'kr' and endings like 'ak', 'uk'.

Example: "GRONDAK MURK"

Alien

Exotic and strange with unusual consonants like 'x', 'z', 'q' and extended vowels. Creates truly otherworldly sounds.

Example: "xraazu kxeev"

Mystical

Arcane and magical with breathy sounds like 'sh', 'th', 'ph' and mystical vowel combinations. Perfect for spells.

Example: "Shaelaeth Mhor"

Robotic

Mechanical and precise with numeric elements and sharp consonants. Features endings like '-tron', '-bot', '-oid'.

Example: "KRIPT-0 TRON-X9"

Korean

Soft, rhythmic language with distinct consonant groups and flowing vowels. Features double consonants like 'kk', 'tt', 'pp'.

example: "gamsa hamnida"

Chinese

Tonal and concise with specific consonant initials and rich vowel finals. Features sounds like 'zh', 'ch', 'sh', 'ang', 'eng'.

example: "zhongwen hao"

Japanese

Gentle and polite with simple syllable structure and soft endings. Features combinations like 'ky', 'sh', 'ch', 'ny'.

example: "konnichiwa desu"

Ancient

Classical and timeless with Greek/Latin influences. Features aspirated consonants like 'th', 'ph', 'kh' and Latin endings.

Example: "Philemon Aurelius"
