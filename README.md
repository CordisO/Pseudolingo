# Pseudolingo Pro

AI-Powered Language Architect

Pseudolingo Pro is a tool for writers, gamers, and world-builders. It turns English sentences into unique, believable fictional languages.

🚀 Quick Summary

What it does: Translates English into "Real" sounding fictional dialects.

The Magic: Follow linguistic rules (not just random letters).

The Look: A tactile, 3D interface that feels like a real machine.

✨ Key Features

🎭 Archetype Styles: Choose from High Elvish, Iron Dwarven, Nebula Alien, and more.

🌓 Dark & Light Mode: Easy on the eyes, no matter your preference.

📱 Mobile Friendly: Works on phones, tablets, and desktops.

✨ Future Improvements

🗣️ Pronunciation Guides: Every translation includes a "How-to-say-it" guide.

📚 Linguistic Facts: Learn why the language sounds the way it does.


🛠️ How to Use

Type your sentence in the box.

Choose your style (e.g., Elvish).

Click "Construct Language."

Copy your new language to use in your story or game!

💻 Tech Stack

Language: HTML, CSS, JavaScript

AI Brain: Gemini 2.5 Flash API

Icons: FontAwesome

🌈 Accessibility Features

I built this project with everyone in mind:

ADHD Friendly: Clear headings, short bullet points, and visual emojis for easy scanning.

Dyslexia Friendly: High contrast colors and clean, spaced-out typography.

Tactile Feedback: Buttons that physically "sink" when clicked so you know the action worked.

🔧 Installation

Clone the repository.

Open index.html in your browser.

Note: An API key is required for the AI features to work.
